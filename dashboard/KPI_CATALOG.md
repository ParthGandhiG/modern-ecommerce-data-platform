# Power BI KPI Catalog

| KPI | Definition | Grain | Business use |
|---|---|---|---|
| Gross Revenue | Sum of completed order-line revenue | Order | Sales performance |
| Orders | Count of completed orders | Order | Demand |
| AOV | Revenue / completed orders | Day/customer | Basket behavior |
| Return Rate | Returned orders / completed+returned | Order | Product/customer quality |
| Customer Revenue | Revenue by customer | Customer | Segmentation |
| Conversion Rate | Purchase events / checkout events | Day | Funnel analysis |
| Data Freshness | Current ingestion time - source max timestamp | Pipeline | Reliability |
| DQ Pass Rate | Passed checks / executed checks | Pipeline run | Trust |
